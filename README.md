# SECOND GANG — мини-приложение магазина

Каталог в стиле Авито для Telegram-канала SECOND GANG. Оплата только по СБП (полная предоплата).

- Товары и реквизиты СБП — в `data.js`, фото — в `img/`.
- Хостинг — GitHub Pages, любой push в `main` обновляет сайт.

## Бот (`bot/`)

Отвечает на /start кнопкой магазина, ставит кнопку меню и пересылает оплаченные заказы админу.
Переменные: `BOT_TOKEN`, `ADMIN_ID`, `WEBAPP_URL`. Запуск: `node bot/server.js`.
После деплоя бота впиши его адрес в `SHOP.api` в `data.js`.
