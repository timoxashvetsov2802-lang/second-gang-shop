# SECOND GANG — мини-приложение магазина

Каталог в стиле Авито для Telegram-канала SECOND GANG. Оплаты и оформления в приложении нет: кнопка «Купить» открывает личку менеджера с готовым сообщением про вещь, об оплате и доставке договариваются там.

- Товары и настройки — в `data.js`, фото — в `img/`.
- Хостинг — GitHub Pages, любой push в `main` обновляет сайт.

## Бот (`bot/`)

Отвечает на /start, принимает заказы, статусы и трек-номера от админов, уведомляет покупателей.
Переменные: `BOT_TOKEN`, `ADMIN_IDS` (через запятую).

- **Хостинг:** Render (бесплатно) по `render.yaml`. Там бот сам включает вебхук и пингует себя раз в 10 минут, чтобы не засыпать.
- **Заказы:** хранятся в `bot/data/orders.json`, копия — закреплённым файлом в чате первого админа с ботом (диск Render стирается при перезапуске, бот поднимает заказы из копии).
- **С ПК:** `TUNNEL=1 node bot/server.js` (long polling + туннель). Не запускай одновременно с Render.
